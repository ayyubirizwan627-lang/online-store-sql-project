
# Online Store Database & Sales Analysis (MySQL)
A MySQL project designed for online store management, customer records, product tracking, and sales analytics.

## Features
- Database schema including tables for customers, products, orders, and order_items.
- Enforced data integrity using PRIMARY KEY, FOREIGN KEY, NOT NULL, and UNIQUE constraints.
- SQL queries covering JOINs, aggregations, GROUP BY, and HAVING clauses for business analysis.

## Tech Stack
- Database: MySQL
- Tool: MySQL Workbench

## How to Run
1. Open online_store_setup.sql in MySQL Workbench.
2. Execute the script to set up the database schema, insert sample data, and run analytics queries.
